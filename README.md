# Adelayo Law website

Responsive HTML, CSS and vanilla JavaScript website.

## Pages
- `index.html` — homepage with cinematic video hero, three-stripe scroll reveal, practice areas and attorney introduction.
- `about.html` — dedicated attorney profile page with the supplied biography and click-to-call appointment link.

## Assets
- `assets/adelayo-hero.mp4` — supplied hero footage.
- `assets/adelayo-attorney.webp` — supplied attorney portrait.

## Run locally
Open the folder in VS Code and use Live Server, or run `python3 -m http.server 8000` from this directory.

The homepage and About page use Host Grotesk and the Adelayo Law brand palette. Layouts adapt across mobile, tablet, laptop and large desktop widths; keyboard focus, skip navigation and reduced-motion preferences are supported.
